WEEK 04 / EXERCISE 03

Read a form input

Listen for the form's submit event to respond to keyboard and button submissions alike. The example uses a label and a live region for accessible feedback.

INTERACTIVE EXAMPLE

form.addEventListener("submit", (event) => {
  event.preventDefault();
  const name = input.value.trim();
  output.textContent = `Hello, ${name}!`;
});
