WEEK 04 / EXERCISE 02

Listen for a click

An event listener runs a function when an event occurs. This example toggles a detail panel and keeps its accessible expanded state in sync.

INTERACTIVE EXAMPLE

This panel appears when its button is activated. Activate the button again to hide it.

button.addEventListener("click", () => {
  const isOpen = button.getAttribute("aria-expanded") === "true";
  button.setAttribute("aria-expanded", String(!isOpen));
  panel.hidden = isOpen;
});
