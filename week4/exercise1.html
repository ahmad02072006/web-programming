WEEK 04 / EXERCISE 01

Update the page

The DOM represents the document as objects JavaScript can inspect and change. Click the button to update the heading.

INTERACTIVE EXAMPLE

The page is ready

const message = document.querySelector("#message");
const button = document.querySelector("#update-button");

button.addEventListener("click", () => {
  message.textContent = "The DOM has been updated!";
});
