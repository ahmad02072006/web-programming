WEEK 05 / EXERCISE 01

Conditions and comparisons

Conditions let a program choose what to do. This example checks a score and displays the corresponding result.

INTERACTIVE EXAMPLE

if (score >= 90) {
  result = "Excellent";
} else if (score >= 70) {
  result = "Good work";
} else {
  result = "Keep practicing";
}
