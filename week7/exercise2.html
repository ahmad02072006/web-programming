WEEK 07 / EXERCISE 02

Random dog photo

Fetch one random image from the free Dog CEO API. The example handles loading and errors, then uses the API response to update the image source and alternative text.

LIVE API RESULT

Choose the button to request a photo.

const response = await fetch(
  "https://dog.ceo/api/breeds/image/random"
);
if (!response.ok) throw new Error("Request failed");

const data = await response.json();
image.src = data.message;
image.alt = "A random dog";
image.hidden = false;

This free public API needs an internet connection. If a request fails, the message will explain that you can try again.
