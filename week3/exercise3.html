WEEK 03 / EXERCISE 03

Responsive CSS Grid

CSS Grid lays content out in rows and columns. Combining auto-fit and minmax() lets the browser choose how many cards fit without a breakpoint for every screen size.

LIVE EXAMPLE

HTML
CSS
JavaScript
Web APIs
.grid {
  display: grid;
  grid-template-columns: repeat(
    auto-fit,
    minmax(130px, 1fr)
  );
  gap: 10px;
}
