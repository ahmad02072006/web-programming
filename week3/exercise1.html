WEEK 03 / EXERCISE 01

Type, color, and spacing

CSS rules select elements and apply visual properties. Padding creates space inside a box; margin creates space outside it; borders and shadows add separation.

LIVE EXAMPLE

Field note 01

Look closer

A little whitespace gives the important details room to breathe.

.card {
  padding: 24px;
  border: 1px solid #d9ddcf;
  border-radius: 14px;
  background: #f7f9f1;
  box-shadow: 0 12px 25px #29351b12;
}

.card h2 {
  margin: 13px 0 8px;
  color: #202b17;
  font-size: 25px;
}
